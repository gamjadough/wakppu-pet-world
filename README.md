# 왁뿌볼 웹 게임 v0.2 · 작은 정원

Google 로그인과 계정 클라우드 저장이 배포된 게임에서 활성화되었습니다. 계정 메뉴에서 로그인하면 서버의 진행상태로 시작합니다. 다른 브라우저로 옮기기 전에 서버 저장 완료를 확인하세요. 설정과 충돌 처리 안내는 [SERVER_SETUP.md](SERVER_SETUP.md)를 참고하세요. 아래의 브라우저 저장 설명은 게스트 모드 기준입니다. 공식 랭킹은 아직 포함하지 않습니다.

HTML, CSS, 순수 JavaScript로 만든 로컬 싱글플레이 부화 게임입니다. 게임을 실행하는 데 패키지 설치, 인터넷, 서버, 계정이 필요하지 않습니다.

**[웹에서 플레이](https://gamjadough.github.io/wakppu-pet-world/)** · **[GitHub 저장소](https://github.com/gamjadough/wakppu-pet-world)**

## 실행 방법

1. 이 폴더의 `index.html`을 Chrome 또는 Edge로 열어 주세요. 파일을 더블클릭하거나 브라우저 창에 끌어 놓으면 됩니다.
2. 하단 **왁뿌볼 부화실**을 열고 기본 볼을 12번 클릭하거나 터치합니다. 버튼에 포커스를 둔 상태에서 Space 또는 Enter도 사용할 수 있습니다. 충분히 큰 화면에서는 부화 결과와 보유 볼을 한 화면에서 보고, 작은 화면에서는 메뉴 안을 위아래로 스와이프합니다. 부화실의 소리 버튼으로 클릭·파괴 소리를 켜거나 끌 수 있습니다.
3. 하단 **펫 인벤토리**를 열어 부화한 펫의 **장착하기**를 누릅니다. 장착한 펫이 중앙 초원에서 돌아다니며 골드를 자동 생산합니다. 맵 위의 펫을 누르면 이름·희귀도·생산량을 볼 수 있습니다.
4. 50 G를 모아 상점에서 오로라 왁뿌볼을 구매합니다. **왁뿌볼 부화실**의 **보유 왁뿌볼**에서 선택한 뒤 깨면 더 높은 희귀도를 노릴 수 있습니다. **펫 도감**에서 발견 기록을 확인하세요.

상단 골드·수익과 하단 메뉴는 항상 보입니다. 상점·부화실·인벤토리·도감은 모두 월드 위 중앙 팝업으로 열리며 맵 크기를 줄이지 않습니다. 팝업의 ×, 바깥 영역, 같은 메뉴 버튼 또는 Escape로 닫습니다. 메뉴를 열어도 이동과 수익 생산은 계속됩니다.

처음에는 장착한 펫이 없어 초당 수익이 0입니다. 첫 펫을 장착해야 생산이 시작됩니다.

정원 오른쪽 위에서 햇살·해질녘 배경을 선택할 수 있습니다. 배경 선택은 저장됩니다. **생활 안내**에서 성격과 궁합 규칙을 확인하고, 정원 아래 목표 버튼으로 부화실이나 인벤토리를 바로 열 수 있습니다. 친구 보너스는 정원 제목 아래 표시됩니다.

## 게임 규칙

- 펫마다 차분한·고집센·다정한·호기심 많은 성격이 있습니다. 종류별 성격은 고정이며 기존 펫도 그대로 이어집니다.
- 서로 잘 맞는 다른 종류의 펫을 함께 장착하면 각자의 생산량이 10% 늘어납니다. 여러 친구가 있어도 10%만 적용하며 싸우는 펫은 응원하지 못합니다. 다정한 친구는 고집센 친구 외의 성격을 응원하고, 차분한 친구와 호기심 많은 친구도 잘 맞습니다.
- 잘 맞는 펫들이 만나면 잠시 함께 놀며 하트가 나타납니다. 고집센 친구가 다른 성격과 만나면 25% 확률로 다툽니다. 같은 종류·같은 고집센 성격은 다투지 않습니다. 만남은 펫별 12초 간격으로 확인합니다.
- 싸우는 두 펫은 이동과 골드 생산을 멈춥니다. 나머지 펫은 계속 생산하고 상단 수익도 실제 생산량으로 바뀝니다.
- 싸우는 펫 중 하나나 월드의 중재 알림을 클릭하면 둘 다 다시 생산·이동합니다. 중재를 놓쳐도 20초 뒤 자동으로 화해합니다. 중재 후 10초 동안은 다른 펫과도 싸우지 않습니다. 클릭 위력 능력은 유지됩니다.
- 싸움과 평화 시간은 저장됩니다. 싸우는 펫을 해제·교체·방생하면 상대의 싸움도 끝나며, 무관한 펫의 방생은 진행 중인 싸움을 유지합니다.
- 시작 골드 0, 무제한 무료 기본 왁뿌볼, 장착 슬롯 3개입니다.
- 볼 1개를 파괴하면 펫 1마리를 받습니다. 부화 중에는 볼 클릭·선택·구매가 잠깁니다.
- 5개 희귀도마다 2종씩 총 10종의 펫이 있습니다. 같은 희귀도 안에서는 각 종류가 같은 확률로 등장합니다.
- 같은 종류가 여러 번 부화하면 별개의 펫으로 보관하며, 각각 장착할 수 있습니다.
- 장착 슬롯이 가득 차면 **가장 최근에 장착한 펫**을 자동으로 해제하고 누른 펫을 장착합니다.
- 인벤토리 위 **추천 구성**은 희귀도, 같은 희귀도에서는 실제 초당 수익 순으로 최대 3마리를 장착합니다. 같은 종류도 각각 장착합니다.
- **방생**은 확인 후 해당 펫을 삭제하고 카드에 표시된 초당 생산량만큼 골드를 한 번 지급합니다. 장착 펫은 월드에서도 제거하며 도감 기록은 유지합니다.
- 생산량은 **장착한 펫의 기본 생산량 + 고유 생산 보너스 + 친구의 응원**의 합입니다. 인벤토리 카드는 고유 생산 보너스까지 포함한 기본 생산량을 표시하고, 월드의 펫 정보와 상단 수익에는 친구의 응원까지 포함한 현재 수익을 표시합니다.
- 클릭 위력은 기본 1 + 장착한 펫의 클릭 보너스 합입니다. 펫 해제 후에도 소유와 발견 기록은 유지됩니다.
- 유료 볼은 구매 시 골드를 차감하고, 부화 시 1개를 소모합니다. 같은 종류가 남아 있으면 그 볼이 계속 나오고, 없으면 무료 기본 볼이 나옵니다.
- 다른 종류의 볼을 선택하면 이전 균열은 초기화됩니다. 볼 자체는 소모되지 않습니다.

| 볼 | 가격 | 필요 균열 | 일반 / 희귀 / 초희귀 / 영웅 / 신화 |
| --- | ---: | ---: | --- |
| 기본 | 무료 | 12 | 70 / 22 / 6 / 1.8 / 0.2% |
| 오로라 | 50 G | 20 | 40 / 35 / 18 / 6 / 1% |
| 네뷸라 | 300 G | 30 | 20 / 35 / 28 / 14 / 3% |
| 태양 | 1,500 G | 45 | 10 / 25 / 35 / 23 / 7% |

## 저장과 초기화

골드, 펫, 장착, 도감, 볼 수량·선택, 진행 중인 균열·소리·배경·다툼 종료 시각을 `localStorage`의 `wakppu-v01` 키에 저장합니다. 행동 직후와 2초마다 자동 저장하고 페이지를 떠날 때도 저장합니다. 부화 보상은 애니메이션 전에 확정·저장됩니다.

펫 월드 개편에서도 저장 키와 버전 1 형식은 유지했습니다. 기존 진행 상태를 그대로 불러옵니다. 맵의 산책 위치·방향·휴식은 임시 화면 상태이며 새로고침 시 다시 배치됩니다. 장착과 생산량은 유지됩니다.

손상된 JSON은 기본 상태로 복구하고, 잘못된 개별 필드는 검증해 복구합니다. 저장소가 차단되거나 용량이 부족하면 하단에 저장 불가 안내를 표시하며 현재 플레이는 계속됩니다. **게임 초기화**는 확인창에서 승인한 경우에만 진행됩니다.

저장은 해당 브라우저·프로필에만 유지됩니다. 파일 경로나 브라우저를 변경하면 다른 저장으로 취급될 수 있습니다. 시크릿 모드와 브라우저 데이터 삭제는 저장을 지울 수 있습니다. 가장 안정적인 유지를 위해 같은 파일 위치와 브라우저를 사용하세요. 여러 탭의 저장 병합은 지원하지 않으므로 한 탭에서 플레이하세요.

브라우저를 닫은 동안의 오프라인 수익은 없습니다. 열린 탭에서 실제 경과 시간으로 생산하며, 백그라운드에서 늦어진 생산 틱은 최대 60초까지만 계산합니다. 보호 한도는 골드 10¹⁵, 펫 10,000마리, 유료 볼 종류별 9,999개입니다.

## 초보자를 위한 수정 안내

`game.js` 위쪽의 `BALLS`에서 가격(`price`), 필요 균열(`clicks`), 확률(`odds`)을 바꿀 수 있습니다. 확률 5개의 합은 100이어야 합니다. `PETS`에서 이름, 희귀도(0~4), 기본 생산량(`rate`), 생산 보너스(`bonus`), 클릭 보너스(`power`), 설명(`ability`)을 수정하세요. 능력 값을 변경하면 설명도 함께 바꿔 주세요.

`style.css` 첫 줄의 색상 변수를 수정하면 화면의 주요 색상이 바뀝니다. 설정을 크게 변경한 뒤에는 기존 저장과의 혼동을 피하도록 게임을 초기화하세요.

펫 월드 색상과 모습은 `style.css`의 **펫 월드** 주석 아래에 있습니다. `index.html`의 `map-terrain`은 연못·길, `map-decorations`는 나무·꽃·표지판입니다. `world.js`는 장식과 독립적으로 펫의 움직임만 담당합니다. 펫마다 인벤토리 번호를 키로 사용해 같은 종류가 여러 마리여도 각각 움직이며, 잠시 쉬거나 방향을 바꾸고 가까워지면 서로 떨어집니다.

## 테스트

게임 실행과 별개로 개발자용 검사에는 Node.js, Playwright 및 Chrome이 필요합니다. 기존 Playwright가 있는 환경에서 `node tests/game.test.cjs`와 `node tests/fights.test.cjs`로 실행합니다. 다른 위치에 설치되어 있으면 `TEST_PLAYWRIGHT_MODULE` 환경 변수에 모듈 경로를 지정합니다. `TEST_GAME_URL`로 배포 주소를 지정해 같은 검사를 실행할 수 있고 `TEST_SCREENSHOT_DIR`로 화면 저장 폴더를 바꿀 수 있습니다. 검사에는 별도 브라우저 컨텍스트를 사용하므로 사용자의 게임 저장은 건드리지 않습니다.

모바일 검사는 `node tests/mobile.test.cjs`로 실행합니다. 320×568부터 430×932까지 세로 화면 4종과 가로 화면 3종에서 터치로 부화·구매·장착·저장을 검사합니다. 버튼은 최소 44px 높이로 유지하고, 가로 모드의 부화실은 두 열로 표시합니다. 브라우저 주소 표시줄 변화와 노치·홈 영역에 맞춰 공간을 확보하며, 짧은 화면에서는 볼을 축소하는 대신 메뉴 내부를 스크롤합니다. 화면 회전은 열린 메뉴와 게임 진행을 유지합니다.

실행한 테스트 결과는 `TEST_RESULTS.md`에 기록했습니다. 계정 서버 저장과 Google 로그인을 지원하며, 온라인 거래·멀티플레이·공식 랭킹은 포함하지 않습니다.

## 인벤토리 관리

등급 필터로 전체 또는 일반·희귀·초희귀·영웅·신화를 보고, 정렬에서 얻은 순(먼저 얻은 펫부터)·등급 오름차순·내림차순을 선택합니다. 같은 등급은 얻은 순으로 표시합니다.

카드의 방생 선택 또는 표시된 펫 전체 선택으로 고른 뒤 선택 방생을 누르면 선택 수와 총 보상을 확인하고 함께 방생합니다. 장착 펫은 일괄 방생에서 제외하며, 도감은 유지합니다. 필터 변경 시 선택을 해제하고 정렬 변경 시 선택은 유지합니다. 선택한 펫을 장착하면 선택에서 제외하며, 개별 방생 후에도 선택을 해제합니다. 선택 상태는 새로고침 시 초기화됩니다.

`node tests/inventory.test.cjs`로 전용 검사를 실행합니다. 기존 회귀·모바일 검사와 같은 환경 변수를 사용할 수 있습니다.

이번 버전의 업데이트 방향은 생활 공간 → 성격과 관계 → 성장·중복 활용 → 탐험·꾸미기 순입니다. 성장·탐험은 이번 버전에 아직 포함하지 않았습니다.
